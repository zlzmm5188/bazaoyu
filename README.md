# Bazaoyu - Telegram Web

A modern, responsive Telegram web client built with vanilla HTML, CSS, and JavaScript.

## Features

- 🎨 **Modern UI** - Clean, Telegram-inspired interface
- 💬 **Real-time Messaging** - Send and receive messages with auto-responses
- 🔍 **Search** - Search through chats and messages
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🚀 **Multiple Chats** - Switch between User Chat, Group Chat, and Channel
- ⏰ **Timestamps** - Real-time message timestamps
- 🎯 **Interactive** - Click to select chats, type and send messages

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser, or
3. Serve with a simple HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
4. Navigate to `http://localhost:8000`

## File Structure

- `index.html` - Main HTML structure
- `style.css` - CSS styling and responsive design
- `script.js` - JavaScript functionality for messaging and interactions

## Features in Detail

### Messaging
- Type messages in the input field
- Press Enter or click the send button to send
- Auto-response simulation for realistic chat experience
- Message timestamps and sender identification

### Chat Management
- Three pre-configured chats: User Chat, Group Chat, and Channel
- Click any chat to switch and view its messages
- Real-time last message updates in sidebar

### Search
- Search through chat names and last messages
- Real-time filtering as you type
- Clear search results instantly

### Responsive Design
- Mobile-friendly interface
- Adaptive layout for different screen sizes
- Touch-friendly controls

## Technology Stack

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with flexbox and grid
- **Vanilla JavaScript** - No frameworks, pure JS functionality
- **Responsive Design** - CSS media queries for mobile support
